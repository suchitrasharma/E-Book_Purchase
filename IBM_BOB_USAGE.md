# IBM Bob — Usage in Book Worm Development

This document records how IBM Bob (AI-assisted development tool) was used throughout the development of the Book Worm e-bookstore project.

---

## What is IBM Bob?

IBM Bob is an AI-powered software engineering assistant integrated into the development environment. It helps developers write, refactor, debug, and document code through natural-language conversation, inline code generation, and agentic task execution across files.

---

## How IBM Bob Was Used in This Project

### 1. Database Schema Design

IBM Bob was used to design the full SQLite schema in `server/src/db.js`. The prompt described the application requirements — users, books, cart, wishlist, orders — and Bob generated the complete `initSchema()` function with all 7 tables, foreign key relationships, default values, and Promise-based query helpers (`dbRun`, `dbGet`, `dbAll`).

**Prompt used:**
> "Design a SQLite schema for a full-stack e-bookstore with users, addresses, books, wishlist, cart, reviews, and orders. Wrap all queries in async/await helpers."

---

### 2. REST API Development

The entire `server/src/server.js` was built with IBM Bob's assistance. Each API section was generated through iterative prompts:

- Authentication routes (`/api/auth/register`, `/api/auth/login`) with bcrypt hashing and JWT signing
- Books API with dynamic filter query building (search, category, language, format, price range, sort)
- Cart upsert logic that increments quantity if a book already exists in the cart
- Checkout endpoint with GST tax calculation, coupon code validation, order creation, and cart clearance
- Admin stats aggregation using SQL `SUM` and `COUNT` queries

**Example prompt:**
> "Write an Express route POST /api/orders/checkout that calculates 12% tax, applies a coupon discount, saves the order and order items to SQLite, and clears the user's cart."

---

### 3. Frontend State Management

The single-page application architecture in `client/app.js` was designed with IBM Bob. Bob suggested the central `state` object pattern and the `navigate()` function that swaps views by re-rendering the `#appContainer` div — avoiding the need for a frontend framework entirely.

**Example prompt:**
> "Design a vanilla JavaScript SPA state manager with a navigate function that renders different views (home, detail, checkout, orders, wishlist) into a single container div."

---

### 4. UI Component Generation

IBM Bob generated all HTML template strings for the UI views — the book card layout, detail page, checkout form, payment modal, and success confirmation modal. The dark theme color palette (`#121316` background, `#2563eb` brand blue) was maintained consistently across all components with Bob's help.

**Example prompt:**
> "Create a dark-themed horizontal book card component in Tailwind CSS with a cover thumbnail, title, author, tags, price, delivery estimate, wishlist toggle, and add to cart button."

---

### 5. JWT Authentication Middleware

The `server/src/auth.js` middleware file was generated by IBM Bob, including both the `authenticateToken` middleware (Bearer token extraction and JWT verification) and the `authorizeAdmin` role-check middleware.

**Example prompt:**
> "Write Express middleware to authenticate a JWT Bearer token and a separate middleware to check if the user role is admin."

---

### 6. Seed Data

IBM Bob generated the full `server/src/seed.js` script including 9 realistic books across 3 catalog sections (Recommended, Bestsellers, New Launches), 2 user accounts with bcrypt-hashed passwords, a default delivery address, and a pre-seeded review — all matching the design wireframes.

---

### 7. Debugging & Refactoring

During development, IBM Bob was used to:
- Debug CORS issues between the frontend and the Express backend
- Fix SQLite `UNIQUE constraint` errors on the cart and wishlist tables
- Refactor the checkout flow to correctly pass delivery address as a JSON string to the database
- Resolve the cart badge count update not reflecting guest cart items from localStorage

---

### 8. Documentation

All three documentation files in this project were generated with IBM Bob:
- `README.md` — project overview, quickstart guide, architecture diagram
- `API.md` — full REST API reference with request/response examples
- `IBM_BOB_USAGE.md` — this file
